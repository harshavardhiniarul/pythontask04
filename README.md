# Problem Solving with Python

## Overview
This repository contains solutions to a series of foundational Python
programming exercises completed as part of an internship assignment.
The exercises are organized into multiple levels, with each level
presenting a set of problems.

## Objective
The goal of these exercises is to develop strong problem-solving
skills in Python by working through progressively structured
problems covering numbers, strings, arrays, and pattern-based logic.

## Structure
Each level consists of a series of individually numbered problems.
Every problem includes:
- A clearly stated question
- A defined input (where applicable)
- An expected output (test case)

Solutions are organized as separate Python files, with each file
corresponding to one problem from the exercise set.



## Tools & Environment
- **Language:** Python 3
- **Execution:** Standard Python interpreter, run via command line
